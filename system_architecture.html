System Overview

Hệ thống là một ứng dụng RAG nhiều service. Frontend React gọi duy nhất Backend/Orchestrator. Backend quản lý auth, metadata, file upload, lịch sử chat và điều phối các service nội bộ: Ingestion để parse/chunk tài liệu, Retrieval để index/search trên Qdrant và BM25, Ollama Service để proxy tới Ollama runtime.

RAG FastAPI React + Vite Qdrant Ollama SQLite
🧭API trung tâm

Backend chạy tại :8000, expose /api/auth, /api/documents, /api/chat, /api/users.

📄Index tài liệu

PDF/TXT/MD được parse thành Markdown, chia theo mô hình section-aware parent-child, parent lưu SQLite, child index vào Qdrant.

🔎Hybrid retrieval

Retrieval Service kết hợp vector search, BM25 SQLite FTS5, RRF ranking, BGE reranker và parent expansion.

🧠LLM shield

Ollama Service tại :8200 bảo vệ Ollama thật bằng x-api-key, ép model, giới hạn rate và kích thước input.

Thành phần chính

Các thành phần được ghi nhận từ README, .env.example, requirements và source router/config.

⚛️Frontend

React + Vite UI cho login, chat, admin documents/users. Dùng Axios cho API, Fetch stream cho /api/chat/query, ReactMarkdown hiển thị câu trả lời và citation.

🛡️Backend/API

FastAPI + SQLAlchemy + SQLite. Quản lý JWT, upload, document CRUD, chat sessions/messages, background indexing và RAG orchestration.

📥Ingestion

FastAPI service cho /v1/parse, /v1/split, /v1/index/build, /v1/index/build-from-markdown, /v1/index/upsert.

🔎Retrieval

FastAPI service cho /v1/search/hybrid, /v1/retrieve, /v1/search/vector, /v1/index/chunks, DELETE /v1/index/document/{id}.

🧠Ollama/LLM

Ollama shield expose /api/chat, /api/embed, /v1/embed, /v1/orchestrator/classify. Upstream là Ollama runtime :11434.

🗄️Storage

SQLite metadata DB, filesystem uploads/cache/logs, Qdrant embedded hoặc remote. BM25 đọc từ SQLite FTS5 trên parent chunks.

Key Design Notes

Các quyết định thiết kế được README/source nhắc rõ.

Backend là entrypoint duy nhất cho Frontend

Frontend dùng /api; các service Ingestion/Retrieval/Ollama là nội bộ.

Retrieval Service sở hữu Vector DB

Backend không nên query Qdrant trực tiếp trong runtime chat/retrieval; search/index/delete đi qua Retrieval API.

Section-aware parent-child indexing

Parent chunks là section/heading text lưu trong SQLite; child chunks nhỏ hơn được embed/index vào Qdrant.

Hybrid retrieval mặc định giàu tín hiệu

Vector search + BM25 FTS5 + RRF; reranker BAAI/bge-reranker-v2-m3 được bật trong retrieval_service/.env.example.

Ollama Shield kiểm soát inference

Shield ép model server-side, giới hạn prompt/input/message/num_predict và rate limit; backend model có thể để default.

Async indexing chạy in-process

Backend dùng FastAPI BackgroundTasks; nếu backend restart thì job đang chạy có thể dừng, dùng /api/documents/reindex để queue lại.

Qdrant embedded là mặc định local

QDRANT_URL rỗng dùng path local; remote Qdrant được khuyến nghị khi nhiều vectors hoặc cần scale.

Chat streaming qua SSE

Backend trả event session, output_mode, sources, token, done cho frontend.

Unclear / Need Verification

Phần này đã được chuẩn hóa theo source code hiện tại. Các điểm dưới đây không được dùng làm cạnh chính trong sơ đồ nếu source không chứng minh kết nối đó.

Source code is source of truth
  • Chat không được vẽ là public: source backend/app/api/chat.py dùng get_current_user cho sessions và /api/chat/query; frontend cũng redirect về login trước khi vào /chat. Vì vậy sơ đồ dùng luồng JWT-authenticated.
  • Endpoint auth/users theo source: source có POST /api/auth/login, GET /api/auth/me, và GET/POST/PUT/DELETE /api/users. Không vẽ /api/auth/register hoặc GET /api/users/{user_id} vì không thấy trong router hiện tại.
  • Embedding khi index theo source: source cho thấy Ingestion /v1/index/upsert chỉ chuẩn bị batch và gọi Retrieval /v1/index/chunks; Retrieval gọi Ollama Service /v1/embed. Vì vậy không vẽ cạnh Ingestion → Ollama cho embedding.
  • Qdrant ownership theo source: backend/app/core/settings.py không đọc QDRANT_*; retrieval_service/app/core/settings.py đọc QDRANT_URL, QDRANT_PATH, QDRANT_COLLECTION_NAME. Vì vậy sơ đồ không có cạnh Backend → Qdrant trực tiếp.
  • Collection Qdrant theo source/env template: default trong retrieval_service/app/core/settings.py và retrieval_service/.env.example là global_child_chunks. Nếu runtime .env khác, cần xác minh ở môi trường chạy thực tế.
  • PDF parser mode: source default là legacy, nhưng ingestion_service/.env.example đặt marker. Sơ đồ không phụ thuộc parser mode; runtime thực tế lấy theo biến PDF_PARSER_MODE.
  • Docker/Cloudflare Tunnel: README có nhắc, nhưng không thấy Dockerfile*, docker-compose*.yml hoặc flow Cloudflare trong source được đọc. Vì vậy không vẽ các thành phần này trong kiến trúc runtime.
  • Query rewrite: source Retrieval có biến QUERY_REWRITE_ENABLED và module rewrite, nhưng env template đặt false. Sơ đồ retrieval chính không coi query rewrite là bước mặc định.
